# Changelog

## 0.1.2 - 2026-10-07

- Thread rows are indented under their project heading, with a subtle vertical guide for visual grouping.

- Projects and sections sort by name ascending, with natural numeric ordering (1.9, 1.10, 1.12). Activity no longer moves group headings.

## 0.1.1 - 2026-10-07

- Rows no longer show a time. Status moved to the right of the title: dot for unread, spinner for a working agent, separate glyphs for a question, failure, queued message, background work and draft.
- Removed the time format setting, which only served the row times.

## 0.1.0 - 2026-10-07

- First public release of Show Latest Threads.
